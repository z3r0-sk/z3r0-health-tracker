WEIGHT TRACKER v1 — CONNECTED MOBILE PWA

This version connects the existing Weight Tracker UI to the Supabase project configured for this tracker.
The browser-safe publishable key is embedded in the app; Supabase documents publishable keys as safe for browser/mobile apps when Row Level Security is enabled.

Deploy the folder to an HTTPS host such as Netlify, then open the URL in Chrome on Android and choose Add to Home screen.
